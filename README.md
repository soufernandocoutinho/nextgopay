# NextGo Pay

Página de vendas e apresentação comercial do sistema **NextGo Pay**, desenvolvida pela **FC Soluções Digitais / Guia Panorama**.

O NextGo Pay é uma plataforma de pagamentos online criada para simplificar recebimentos e a organização financeira de empresas. A página apresenta recursos como:

- links de pagamento;
- recebimentos por Pix, cartão e boleto;
- planos e cobranças recorrentes;
- cadastro de clientes;
- acompanhamento de movimentações e recebimentos;
- integração com os sistemas Next Go Orders e Next Go Agenda;
- utilização independente da plataforma.

A página foi construída como um site estático, com foco em apresentação responsiva, organização das informações comerciais, acessibilidade e integração de conteúdo para mecanismos de busca.

## Tecnologias utilizadas

- **HTML5** para a estrutura da página;
- **CSS3** para os estilos e o layout responsivo;
- **Bootstrap 5.3.3** para componentes e grade responsiva;
- **JavaScript** para interações da interface;
- **Schema.org (JSON-LD)** para dados estruturados e SEO;
- **Google Analytics, Google Ads, Google Tag Manager, Meta Pixel e Cloudflare Web Analytics** para ferramentas de medição opcionais, carregadas conforme o consentimento do usuário.

## Estrutura principal

- `index.html`: conteúdo, metadados, dados estruturados e estrutura da landing page;
- `assets/css/`: estilos da página e do aviso de consentimento;
- `assets/js/`: scripts de interação e gerenciamento de consentimento de cookies;
- `assets/img/`: identidade visual e imagens do painel da plataforma.
